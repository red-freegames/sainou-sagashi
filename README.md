# 才能探し 〜才能を見つけよう〜

16のミニゲームで「センス」と呼ばれてきた才能を実測するブラウザゲーム（1ファイル）。
結果は異世界風ステータス表＋ジョブ＋二つ名で表示されます。

▶ プレイ: https://red-freegames.github.io/sainou-sagashi/

## 遊び方
`index.html` をブラウザで開くだけで遊べます。サーバーやビルドは不要です。
名前を入力して「鑑定をはじめる」を押すと、全16種目の鑑定が始まります（約5〜6分）。
種目だけを切り出した単発プレイもタイトル画面から選べます。
